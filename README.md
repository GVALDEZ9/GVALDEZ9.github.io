# GVALDEZ9.github.io

Academic website starter for Gia Valdez.

This site is built from Markdown files so it can be uploaded directly to a GitHub Pages repository named `GVALDEZ9.github.io`.

Main files:

* `index.md`: homepage
* `cv.md`: public CV page
* `_config.yml`: simple GitHub Pages configuration
* `.nojekyll`: keeps GitHub Pages from transforming files unexpectedly

The PDF CV is included at `assets/Gia_Valdez_CV_2026.pdf`.
